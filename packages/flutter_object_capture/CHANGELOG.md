## 0.0.1

- Initial scaffold: package layout, iOS plugin registration (`flutter_object_capture/method_channel`, `flutter_object_capture/event_channel`), example app. 
- Dart API: `ObjectCaptureProcessor` (`isSupported`, `getLimits`, `reconstruct` as a stream of sealed `ReconstructionEvent`s, `cancel`, `dispose`), `ObjectCaptureConfiguration` (`FeatureSensitivity`, `SampleOrdering`), `ObjectCaptureLimits`, typed exceptions, `.usdz` output path validation.
- iOS native layer: `ObjectCaptureController` (one `PhotogrammetrySession` per job, `.reduced` USDZ output, progress/sample/notice/completed events on the main thread, cancel and error mapping), `ObjectCaptureOutputConverter`, `ObjectCaptureErrorMapper`, `#if canImport(RealityKit)` fallback answering `not_supported`. Not yet run on a device.
- Guided capture: `ObjectCaptureProcessor.captureImages` / `isGuidedCaptureSupported` (iOS 17+, `ObjectCaptureSession` in a modal SwiftUI screen), `ObjectCaptureSessionResult`, new exceptions `DirectoryNotEmptyException`, `CaptureSensorFailedException`, `CaptureTrackingFailedException`, `CaptureFailedException`; example app "Capture photos" action; `NSCameraUsageDescription` documented. Not yet run on a device.
- macOS 12+ support: plugin sources moved from `ios/` to a shared `darwin/` folder (`sharedDarwinSource`, podspec and Swift Package for both platforms), platform code guarded with `#if os(iOS)` / `#if os(macOS)`. Guided capture reports unsupported on macOS.
- `ObjectDetail` (`preview`, `reduced`, `medium`, `full`, `raw`) and `ObjectOutputFormat` (`usdz`, `objDirectory`) added to `ObjectCaptureConfiguration` (defaults `reduced` / `usdz`, non-breaking). iOS rejects any other detail with the new `UnsupportedDetailException` (`unsupported_detail`) and `objDirectory` with `InvalidOutputPathException`; macOS accepts all. `InvalidOutputPathException` now takes the output format. Poses and custom detail are not wired.
- Example app: macOS runner, detail selector on macOS, Capture photos button hidden when guided capture is unsupported.
